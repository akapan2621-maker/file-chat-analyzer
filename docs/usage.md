# File Chat Analyzer — คู่มือการใช้งาน

## เริ่มต้นใช้งาน

```bash
cd /opt/data/projects/file-chat-analyzer
pip install -r requirements.txt
streamlit run ui/app.py
```

## หน้าเว็บมีส่วนประกอบอะไรบ้าง

### ด้านซ้าย (Sidebar)
- **อัปโหลดไฟล์**: เลือกไฟล์หลายไฟล์พร้อมกันได้ รองรับ CSV, TXT, JSON, PNG, JPG, PDF, PY, MQ4/MQ5, LOG ฯลฯ
- **รายการไฟล์**: แสดงไฟล์ที่อัปโหลดไว้ทั้งหมด พร้อมปุ่มลบไฟล์รายตัว หรือลบทั้งหมด

### ส่วนกลาง (แชท)
- พิมพ์คำถามในช่องแชทด้านล่าง
- AI จะอ่านไฟล์ที่แนบมาแล้วตอบกลับ
- ประวัติแชทถูกเก็บไว้ในหน้าเว็บจนกว่าจะกดล้าง

## ตัวอย่างคำถามที่ถามได้

- "ช่วยวิเคราะห์ผล backtest ว่า drawdown สูงสุดเท่าไหร่ และคุ้มค่ามั้ยถ้าเอาไปใช้จริง"
- "อ่านโค้ด MQL5 นี้แล้วบอกว่ามี bug ตรงไหนบ้าง"
- "สรุปสำคัญจากไฟล์ CSV นี้ว่ามีเทรนด์อะไรน่าสนใจ"
- "รูปภาพนี้แสดงอะไร และเกี่ยวข้องกับคำถามของฉันยังไง"

## หมายเหตุสำหรับการเชื่อมต่อ LLM จริง

ปัจจุบันเว็บนี้แสดง **prompt ที่สร้างขึ้น** เพื่อให้นำไปใช้กับ LLM ได้ทันที

ถ้าต้องการให้ตอบอัตโนมัติในหน้าเว็บ ให้แก้ไขส่วนใน `ui/app.py` ที่แสดง `st.info("💡 ...")` แล้วเรียก API LLM ตัวอย่าง:

```python
import openai

response = openai.chat.completions.create(
    model="gpt-4o-mini",
    messages=[{"role": "user", "content": full_prompt}],
)
st.markdown(response.choices[0].message.content)
```

หรือเชื่อมต่อกับ Hermes agent ตามที่ระบบรองรับอยู่แล้ว
