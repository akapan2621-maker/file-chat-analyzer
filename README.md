# File Chat Analyzer

เว็บแชทสำหรับอัปโหลดไฟล์ทุกประเภท แล้วให้ AI วิเคราะห์ข้อมูลได้อย่างอิสระ

## โครงสร้างโปรเจกต์

```
file-chat-analyzer/
├── ui/app.py              # Streamlit หน้าเว็บหลัก (แชท + อัปโหลดไฟล์)
├── src/file_handler.py    # อ่าน/จัดการไฟล์ที่อัปโหลด
├── src/analyzer.py        # วิเคราะห์เนื้อหาไฟล์ด้วย AI
├── output/                # เก็บไฟล์ที่อัปโหลด + รายงานวิเคราะห์
├── uploads/               # ไฟล์อัปโหลดชั่วคราว
└── requirements.txt       # dependency
```

## วิธีติดตั้งและรัน

```bash
# เข้าโฟลเดอร์โปรเจกต์
cd /opt/data/projects/file-chat-analyzer

# ติดตั้ง dependency
pip install -r requirements.txt

# รันเว็บแอป
streamlit run ui/app.py
```

## ฟีเจอร์หลัก

- ✅ อัปโหลดไฟล์ได้หลายไฟล์พร้อมกัน (CSV, TXT, JSON, PNG, JPG, PDF, PY, MQ4/MQ5, ฯลฯ)
- ✅ แชทกับ AI พร้อมแนบไฟล์ที่อัปโหลดไว้
- ✅ AI อ่านเนื้อหาไฟล์แล้ววิเคราะห์ (สรุป, หาจุดเด่นจุดอ่อน, เสนอแนะ)
- ✅ เก็บประวัติแชทในแต่ละ session
- ✅ ส่งออกรายงานวิเคราะห์เป็นไฟล์ Markdown
- ✅ รองรับภาษาไทยเต็มรูปแบบ

## ตัวอย่างการใช้งาน

1. เปิดเว็บจาก Streamlit
2. อัปโหลดไฟล์ (เช่น backtest result, โค้ด EA, รายงานการเงิน, รูปแชร์ตต่างๆ)
3. พิมพ์คำถามในแชท เช่น "ช่วยวิเคราะห์ว่าไฟล์นี้มีจุดอ่อนตรงไหนบ้าง"
4. AI จะอ่านไฟล์ที่แนบแล้วตอบกลับเป็นภาษาไทย
